# Java

Учебные задачи по Java. Репозиторий открывается как один проект IntelliJ IDEA,
каждая задача лежит в отдельной папке-модуле.

## Задачи

| Папка | Задача | Решение |
| --- | --- | --- |
| `Task_1_1_Brackets` | 1.1 Проверка скобок | стек ожидаемых закрывающих скобок, время O(n), память O(n) |

## Как запустить

В IntelliJ IDEA: открыть папку репозитория, выбрать конфигурацию `Task 1.1 Brackets`
и нажать Run. Программа ждёт строку со скобками в консоли.

В терминале:

```bash
cd Task_1_1_Brackets
javac Solution.java
java Solution
```

Проект собран на Temurin JDK 25.
